# Anki Cards OOP

Консольное приложение для тренировки словарного запаса на английском языке по принципу карточек Anki.

Пользователь может загружать слова из файла или по ссылке, добавлять новые пары «слово — перевод», проходить тренировки, искать перевод слова и сохранять обновлённый словарь.

## Возможности

- тренировка перевода случайных слов;
- тренировка до первой ошибки;
- тренировка с ограничением по времени;
- добавление новых слов;
- просмотр всех слов;
- поиск перевода;
- загрузка и сохранение слов в `.txt`, `.tsv`, `.json`;
- загрузка слов из JSON по HTTP-ссылке.

## Установка

Создайте и активируйте виртуальное окружение:

```bash
python -m venv venv
source venv/bin/activate
```

Установите проект вместе с инструментами разработки:

```bash
python -m pip install -e ".[dev]"
```

## Запуск

Запуск:

```bash
anki
```

Запуск с примером файла из проекта:

```bash
anki --source src/anki/words.txt
```

Запуск с собственным файлом:

```bash
anki --source parh/to/words.txt
anki --source path/to/words.tsv
anki --source path/to/words.json
```

## Форматы файлов

В проекте есть пример файла со словами:

```bash
src/anki/words.txt
```

Файл `.txt` хранит пары через запятую:

```text
дом,house
кот,cat
собака,dog
```

Также приложение поддерживает пользовательские файлы `.tsv` и `.json`.

Файл `.tsv` хранит пары через табуляцию:

```text
дом	house
кот	cat
собака	dog
```

Файл `.json` хранит словарь:

```json
{
  "дом": "house",
  "кот": "cat",
  "собака": "dog"
}
```

## Проверки

Запуск тестов:

```bash
pytest -q
```

Проверка типов:

```bash
python -m mypy src/anki/
```

Проверка стиля:

```bash
python -m ruff check src/anki/*.py
```

Проверка форматирования:

```bash
python -m black --check src/anki/*.py
```
